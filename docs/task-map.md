# Customer Experience — Task Map (Demo)

Each task: Trigger → Input → Decision → Action → Output → Systems → Frequency → Value → Automatable → Human approval → Failures → Escalation.

## Communication
| Task | Automatable | Escalate when |
|------|-------------|----------------|
| Answer inbound channels | Yes | Customer requests human |
| Greet + disclose hours | Yes | — |
| Social DM intake | Yes (simulated) | Complaints |
| Staff notification | Yes | — |

## Customer management
Identify / create / update / history / preferences — automated with identity merge rules.

## Appointments
Check availability, book, reschedule, cancel, confirm, remind — automated within policy.

## Leads
Capture, qualify, route, CRM create — automated; large commercial quotes → sales human.

## Support
KB FAQ only, ticket create/route — automated; KB miss → escalate.

## Escalation (required human)
Safety, complaints, billing disputes, legal, low confidence, outside authority.

## Administrative
Notes, summaries, follow-ups, documentation — automated.
