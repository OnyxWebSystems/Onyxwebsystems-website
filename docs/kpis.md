# Demo KPI Thresholds

Thresholds are targets for a high-performing front desk, justified for HVAC inbound operations:

| KPI | Target | Why |
|-----|--------|-----|
| Call answer rate | ≥ 98% | Missed calls are the primary revenue leak in home services |
| First response time | ≤ 10s (automated) | Speed-to-lead dominates conversion |
| Appointment booking success (clear intent + in-area) | ≥ 85% | Core demo outcome |
| Routing accuracy (deterministic rules) | ≥ 95% | Business-critical; not left to LLM alone |
| Escalation precision (CRITICAL safety) | 100% of gas/CO/fire/flood cues | Safety over false negatives |
| KB answer accuracy | 100% of answered FAQs from approved articles | Never invent policy |
| Customer identification (known phone/email) | ≥ 95% | Cross-channel continuity |
| Follow-up completion (scheduled) | ≥ 90% | Recover abandoned intent without spam |
| Human handoff package completeness | 100% include summary + urgency + history | Employee should not ask “what happened?” |

These are operational targets for the product, not guaranteed customer results.
